Python Intensive

The language itself — objects, comprehensions, dicts, generators, files, dataclasses — taught through data handling and pipelines, then extended into a FastAPI backend. Standard library only; no pandas.

How this works: a 7-day date-locked week builds the language from the ground up, each day a prerequisite of the next, ending in a working ETL script written from scratch. From 5 Aug it becomes an open-ended main track: the rest of the language, then FastAPI + pydantic. Practice files are self-checking and need no dependencies — run them with uv run python3 practice/<file>.py.
Why this course exists: the Data Wrangling course teaches pandas but explicitly assumes Python — it glosses comprehensions and lambdas rather than teaching them. This course owns that gap. The two are complementary by design: library questions belong to Data Wrangling, language questions belong here, and pandas never appears in these lessons.
