Day 1 — Names, objects & mutability

TermTiếng Việt (dev-style)In software
objectgiữ nguyên "object" — vùng dữ liệu thật nằm trong bộ nhớThe actual piece of data living in memory, with a type and a value. In Python everything is one — numbers, strings, lists, functions, even classes. Names are attached to objects; the object is the thing that exists.
name (variable)"biến" / "name" — cái nhãn dán lên object, không phải cái hộp chứaA label bound to an object. Python names are not boxes holding values — they are tags stuck onto objects. x = 5 makes the name x point at the object 5; it does not put 5 inside a container called x.
binding / rebinding"gán" — dán nhãn lên object; gán lại là chuyển nhãn sang object khácAssignment attaches a name to an object (binding). Assigning again moves that name to a different object (rebinding) — it never changes the object the name used to point at.
referencegiữ nguyên "reference" — đường trỏ từ tên tới objectThe link from a name to an object. Two names can hold references to the same object, which is why changing it through one name is visible through the other.
alias / aliasinggiữ nguyên "alias" — hai tên cùng trỏ một objectTwo or more names bound to the same object. b = a aliases; it does not copy. The classic Python surprise: mutating through b changes what a shows.
mutable"mutable" — sửa được tại chỗ (list, dict, set)An object whose contents can be changed in place without creating a new object: list, dict, set. Mutation is visible through every name referencing it.
immutable"immutable" — không sửa được, muốn đổi phải tạo object mớiAn object that cannot be changed after creation: int, float, str, tuple, bool. "Changing" one always builds a new object and rebinds the name.
mutate / mutated (in place)"sửa in-place" — đổi ruột object, không tạo cái mớiTo change an object's contents directly — lst.append(x), d["k"] = v. Contrast with rebinding, which swaps which object a name points to and leaves the original untouched.
identity (is)is — hỏi "có phải CÙNG MỘT object không", khác ==Whether two names refer to the very same object, tested with is and shown by id(). Distinct from ==, which asks whether two objects have equal values. Two equal lists can be separate objects.
shallow copy"shallow copy" — copy lớp ngoài, ruột bên trong vẫn dùng chungA new outer object whose elements are still references to the same inner objects. list(a) or a[:] gives one — safe against appends to the outer list, not against mutating a nested list inside it.
deep copy"deep copy" — copy toàn bộ, không dùng chung gì cảA recursive copy of an object and everything nested inside it, via copy.deepcopy(). Nothing is shared with the original — correct but slower, and rarely what you need.
mutable default argument"bẫy default mutable" — đừng để =[] hay ={} làm giá trị mặc địnhPython evaluates a function's default values once, when the function is defined — so a default [] or {} is one object shared by every call, accumulating across calls. The fix is None as the default plus a fresh object inside the body.
garbage collectiongiữ nguyên "GC" — object hết tên trỏ tới thì bị thu hồiAutomatic reclamation of objects nothing refers to any more. Rebinding the last name pointing at an object makes it unreachable, and Python frees it — which is why you never free memory by hand.

Day 2 — Comprehensions & slicing

TermTiếng Việt (dev-style)In software
list comprehensiongiữ nguyên "comprehension" — viết loop thành 1 dòng, tạo list/dict/set mớiA single expression that builds a new list directly from an iterable — [expr for item in iterable if cond] — replacing a for loop whose only job is appending one transformed item per iteration. The SQL parallel: expression is SELECT, the for-clause is FROM, the optional if-clause is WHERE.
dict comprehensiongiữ nguyên "dict comprehension" — comprehension tạo dict, dùng {} và dấu :A comprehension that builds a dict: {key_expr: value_expr for item in iterable}. Curly braces like a set, but with a colon separating key from value.
set comprehensiongiữ nguyên "set comprehension" — comprehension tạo set, dùng {} nhưng không có dấu :A comprehension that builds a set: {expr for item in iterable}. Curly braces like a dict but with no colon — one expression per element, and duplicates collapse since a set holds no repeats.
slicinggiữ nguyên "slicing" — cắt một đoạn của list/string cùng lúc bằng seq[start:stop:step]The seq[start:stop:step] syntax for extracting part of a sequence at once. stop is always exclusive; any of the three parts can be omitted (seq[:n], seq[n:], seq[:]), and a negative step like -1 reverses.
sequencegiữ nguyên "sequence" — dữ liệu có thứ tự, đánh index được (list, tuple, str)An ordered collection indexable by position — list, tuple, and str are the three used constantly. Slicing and positional indexing both rely on this ordering, and both work identically across all three types.
