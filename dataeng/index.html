Data Pipelines: dbt · Kafka · Airflow

Build one real thing and learn the tools by shipping it: a food-delivery data platform in your own public GitHub repo. Order events stream through Kafka into a Postgres warehouse, dbt turns them into tested marts, and Airflow runs it on a schedule.

How this works: a 7-day date-locked week builds one thin slice end to end. Days 1–4: the repo, Postgres, and dbt models, tests and marts. Days 5–6: Kafka feeding the warehouse. Day 7: Airflow orchestrating it, and shipping the README. From 22 Sep it goes open-ended, spending most of its depth on dbt. Every lesson ends with a build step in your repo and a Verify command with the expected output. If the output matches, you've got the win.
How it fits with the other courses: Data Wrangling owns pandas, Python Intensive owns the language, and Backend Foundations owns API design and idempotency as concepts. This course uses all three as bridges and re-teaches none of them. It owns dbt, Kafka, Airflow and warehouse modelling.
