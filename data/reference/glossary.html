Data Wrangling · Reference

Glossary

Every jargon term used in the lessons, in one place. Tiếng Việt column is dev-style — how Vietnamese devs actually say it, not textbook translation.

TermTiếng Việt (dev-style)In software
data wranglingxử lý / làm sạch dữ liệu thô (hay giữ nguyên "wrangle")Cleaning, restructuring, and enriching raw data into a usable shape — the hands-on craft data jobs test in interviews.
ETLETL (giữ nguyên) — biến đổi xong mới nạp vào khoExtract–Transform–Load: pull data from sources, clean/reshape it in a processing step (often Python/pandas), then load the finished result into the destination.
ELTELT (giữ nguyên) — nạp thô vào warehouse trước, biến đổi sauExtract–Load–Transform: raw data lands in the warehouse first and is transformed there, usually with SQL/dbt. The modern default for analytics pipelines.
DataFrameDataFrame (giữ nguyên) — bảng 2 chiều, giống table SQLpandas' central object: a table of named, typed columns with labeled rows. Your SQL table instincts apply to it almost line for line.
SeriesSeries (giữ nguyên) — một cột của DataFrameOne column of a DataFrame: a 1-dimensional labeled array where every value shares one dtype. df["amount"] returns one.
dtypedtype (giữ nguyên) — kiểu dữ liệu của CẢ một cộtThe data type of an entire column (int64, float64, object/string, datetime64…). Per column, not per cell — like a typed column in Postgres.
NumPyNumPy (giữ nguyên) — thư viện mảng nền tảng, pandas chạy trên nóThe foundational library for fast typed arrays in Python. Each DataFrame column is a NumPy array — that's where pandas' speed comes from.
vectorizedvectorized (giữ nguyên) — thao tác cả cột một lượt, không loopApplying an operation to a whole column/array in one call, executed in compiled C, instead of looping over elements in the Python interpreter. The core pandas methodology.
boolean maskmask (hay nói tắt) — mảng True/False để lọc hàngA True/False Series aligned to the rows; indexing a DataFrame with it keeps only the True rows. pandas' WHERE clause: df[df["amount"] > 100].
NaNgiữ nguyên "NaN" — giá trị thiếu, so sánh == luôn ra Falsepandas'/NumPy's marker for missing floating-point data. Detected with isna() — never with ==, since NaN != NaN by IEEE float rules.
NaTgiữ nguyên "NaT" — NaN dành riêng cho cột datetimepandas' missing-value marker specifically for datetime columns — the datetime64 equivalent of NaN.
Indexgiữ nguyên "Index" — nhãn hàng, tách biệt với các cột dữ liệuThe labels attached to a DataFrame's rows, separate from the data columns. .loc looks up by this label; .iloc looks up by raw position regardless of it.
RangeIndexgiữ nguyên "RangeIndex" — index mặc định 0,1,2,3..., không mang ý nghĩa nghiệp vụThe default pandas Index after loading data: 0, 1, 2, 3… — just positions, carrying no business meaning until you set_index a real key.
coerce (errors="coerce")giữ nguyên "coerce" — ép kiểu, lỗi thì thành NaN chứ không crashA conversion mode (pd.to_numeric/pd.to_datetime) that turns unparseable values into NaN/NaT instead of raising — the pandas equivalent of SQL's TRY_CAST.
dropnagiữ nguyên "dropna" — bỏ hàng thiếu dữ liệuRemoves rows (or columns) containing missing values; subset=[...] limits the check to specific columns. SQL cousin: WHERE col IS NOT NULL.
fillnagiữ nguyên "fillna" — điền giá trị thay cho thiếuReplaces missing values with a given value (or a computed one, like a median). SQL cousin: COALESCE(col, value).
mediangiữ nguyên "median" — giá trị giữa khi sắp xếp, ít bị outlier kéo lệchThe middle value of a sorted column — half the values lie above it, half below. A single extreme outlier barely moves it, unlike the mean, which is why it's a safer default fill value.
flag columnflag column — cột đánh dấu, thường là booleanAn extra boolean column (e.g. amount_was_missing) recording a fact about a row — here, whether a value was originally missing before it got filled, so that information isn't silently lost.
groupby / split-apply-combinegiữ nguyên 'split-apply-combine' — chia nhóm, tính từng nhóm, rồi gộp kết quả lạiThe three-step model behind every groupby: SPLIT rows into groups by a key, APPLY a function to each group independently, COMBINE the per-group results back into one Series/DataFrame. groupby() alone only does the split — nothing computes until an aggregation is chained on.
named aggregationgiữ nguyên 'named aggregation' — đặt tên cột kết quả trực tiếp trong .agg()The .agg(new_col=("source_col", "func")), or .agg(new_col="func") on an already-selected column, form — names each output column directly instead of pandas' uglier default auto-generated names from a plain dict.
merge / joingiữ nguyên 'merge' — hàm gộp 2 DataFrame theo cột khóa, tương đương JOIN trong SQLpandas' function for combining two DataFrames row-wise on a shared key column — the direct equivalent of a SQL JOIN. pd.merge(left, right, on="key", how="inner"/"left"/"right"/"outer") controls both the match column and which unmatched rows survive.
indicator / _mergegiữ nguyên 'indicator' / '_merge' — cột đánh dấu hàng khớp ở bên nàoindicator=True on a merge adds a _merge column valued "both", "left_only", or "right_only" per row — the direct way to find rows present on only one side of a join.
suffixes (_x / _y)giữ nguyên 'suffixes' — hậu tố tự thêm khi 2 bảng trùng tên cộtWhen both merged DataFrames share a non-key column name, pandas silently renames both with _x (left) and _y (right) instead of erroring — pass suffixes=(...) to name them clearly yourself.
long formatgiữ nguyên 'long format' — mỗi hàng 1 quan sát, mỗi cột 1 biếnA table shape where each row is one observation and each column is one variable — the natural output shape of SQL SELECT/GROUP BY and every DataFrame used through Lesson 5.
wide formatgiữ nguyên 'wide' — dàn 1 giá trị thành nhiều cột riêngThe same data laid out with a distinct value spread across separate columns instead of separate rows — a spreadsheet pivot table or monthly report's usual shape.
pivot_tablegiữ nguyên 'pivot_table' — hàm dàn bảng long thành wideA pandas DataFrame method reshaping long data into wide: one row per index value, one column per distinct value in columns, cells filled from values via aggfunc.
meltgiữ nguyên 'melt' — hàm dàn bảng wide về lại longA pandas DataFrame method reshaping wide data back into long: id_vars stay as columns, every other column becomes a (var_name, value_name) pair of rows.
window functionwindow function (giữ nguyên) — tính theo nhóm nhưng KHÔNG gộp hàng, khác GROUP BYA SQL feature computing a value across a set of related rows (a PARTITION) without collapsing them into one row per group, unlike GROUP BY. rank() and cumsum() chained after groupby() are pandas' equivalent.
rank()giữ nguyên 'rank()' — đánh số thứ hạng, giống RANK()/ROW_NUMBER() OVER trong SQLA pandas Series method assigning each value its rank within an ordering — the direct analog of SQL's RANK()/ROW_NUMBER() OVER (...) window functions, computed per group when chained after groupby().
rank tie-breaking (method=)giữ nguyên 'method=' — cách xử lý khi 2 giá trị bằng nhaurank()'s method= argument decides what happens when two values tie: "first" breaks ties by row order (like ROW_NUMBER()), "min"/"dense" give tied rows the same rank (like RANK()/DENSE_RANK()).
top N per groupgiữ nguyên 'top N per group' — lấy k dòng đứng đầu mỗi nhómA common interview pattern: within each group, keep only the highest (or lowest) k rows by some ordering — solved in pandas via rank() <= k or sort_values().groupby().head(k), and in SQL via ROW_NUMBER() OVER (PARTITION BY ...) filtered to <= k.
cumsum()giữ nguyên 'cumsum()' — tổng dồn, tương đương SUM() OVER (...)A running/cumulative sum: each row's output is the sum of itself and every prior row (in the current order) — the pandas analog of SQL's SUM() OVER (PARTITION BY ... ORDER BY ...) window frame. Trusts row order only — no ORDER BY argument of its own.
method chainingmethod chaining (giữ nguyên) — nối liên tiếp các method, không đặt tên biến trung gianWriting a sequence of DataFrame method calls back-to-back, each one operating on the result of the last, instead of assigning each intermediate step to its own variable name.
lambdalambda (giữ nguyên) — hàm không tên, viết gọn trong một dòngPython's syntax for a small, unnamed, inline function — lambda d: d + 1 is a function taking d and returning d + 1. Used inside assign() to name the in-progress DataFrame at that exact point in the chain.
.pipe().pipe() (giữ nguyên) — nhét một hàm tùy ý vào giữa chainA DataFrame method that calls a given function with the DataFrame as its argument and returns that function's result, letting a custom multi-line transformation stay inside a chain instead of breaking it into a separate reassigned step.
anti-joinanti-join (giữ nguyên) — merge chỉ giữ lại các hàng KHÔNG khớp bên kiaA merge that keeps only the rows from one side that have NO matching row on the other side — in pandas, a left merge with indicator=True filtered to left_only rows. SQL cousin: WHERE NOT EXISTS (...) or a LEFT JOIN ... WHERE right.key IS NULL.
value_counts()giữ nguyên 'value_counts()' — đếm số lần xuất hiện mỗi giá trị trong 1 cộtA Series method counting occurrences of each distinct value in that one column, sorted by count descending by default — a one-column shortcut for what groupby(col).size() also computes.
.str accessorgiữ nguyên '.str accessor' — gọi hàm xử lý chuỗi trên cả cột cùng lúcThe .str namespace on a Series of strings, exposing vectorized string methods (contains, upper, lower, startswith, split, ...) that run the equivalent Python string method across every row at once instead of looping.
nlargest() / nsmallest()giữ nguyên 'nlargest()/nsmallest()' — lấy N dòng lớn/nhỏ nhất TOÀN BẢNGDataFrame methods returning the N rows with the largest (or smallest) values in a given column, across the whole table with no grouping — equivalent to sort_values(...).head(n) but names the intent directly. Contrast with "top N per group", which needs a groupby first.
duplicated()giữ nguyên 'duplicated()' — đánh dấu True cho các hàng lặp lạiA Series method returning a True/False flag per row, True where that row's full set of column values (or a chosen subset) has already appeared earlier in the DataFrame. Default keep="first" leaves the first occurrence False; keep=False flags every copy including the first.
drop_duplicates()giữ nguyên 'drop_duplicates()' — bỏ các hàng trùng, giữ lại 1 bảnThe DataFrame twin of duplicated() — returns the table with duplicate rows removed instead of a boolean mask, using the same subset/keep keywords. SQL cousin: SELECT DISTINCT, or a keyed dedupe via ROW_NUMBER() OVER (PARTITION BY key ORDER BY ...) = 1.
pct_change()giữ nguyên 'pct_change()' — % thay đổi so với dòng ngay trướcA Series method computing the fractional change between each row and the row immediately before it (in current order) — the pandas analog of hand-writing (curr - LAG(curr) OVER (...)) / LAG(curr) OVER (...) in SQL. Returns a fraction, not a percentage; NaN on the first row of each group since there is no prior value to compare against. Trusts row order only, same as cumsum() — sort first.
apply()giữ nguyên 'apply()' — gọi hàm Python cho từng dòng/cột, bản chất vẫn là loopA DataFrame method that calls a Python function once per row (axis=1) or once per column (axis=0), the opposite of a vectorized column-wise operation — under the hood it IS a Python-level loop, just spelled as a method call. Use only when the logic genuinely can't be expressed as a vectorized call; can be 10-100x slower on large tables.
pd.cut()giữ nguyên 'pd.cut()' — chia số thành các khoảng (bin) có nhãn, chạy vectorizedA pandas function that sorts numeric values into labeled bins/ranges you define with edges (bins=) and names (labels=), entirely vectorized — no per-row Python function call. Default intervals are left-exclusive, right-inclusive: a value exactly on an edge falls into the lower bucket. SQL cousin: a CASE WHEN chain of range comparisons.
rolling windowgiữ nguyên 'rolling window' — cửa sổ trượt kích thước cố định N dòng gần nhấtA pandas method (.rolling(window=N)) computing an aggregation over a fixed-size sliding window of the last N rows (including the current one), sliding forward one row at a time — e.g. a 3-order moving average. The first N-1 rows of each group return NaN, since fewer than N rows are available yet. SQL cousin: a window frame with ROWS BETWEEN N-1 PRECEDING AND CURRENT ROW. Trusts row order only, same as cumsum()/pct_change() — sort first.
expanding windowgiữ nguyên 'expanding window' — cửa sổ lớn dần từ đầu tới dòng hiện tạiA pandas method (.expanding()) computing an aggregation over every row from the start of the group through the current row, growing by one row each step — no fixed size, so even the first row returns a valid (1-row) result, no leading NaN. expanding().sum() is equivalent to cumsum(); expanding() generalizes that same growing-window idea to any aggregation (mean, max, std, …). SQL cousin: ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW.
MultiIndexgiữ nguyên 'MultiIndex' — cột (hoặc hàng) có nhiều tầng, 1 cột = 1 tupleA pandas column (or row) index with more than one level, so a single column is identified by a tuple like ("sum", "2026-01-05") rather than one plain name — the shape pivot_table produces when given more than one aggfunc or values column at once.
stack() / unstack()giữ nguyên 'stack()/unstack()' — kéo 1 tầng cột xuống hàng (stack) hoặc ngược lại (unstack)stack() moves one level of a MultiIndex column header down into the row index; unstack() is its inverse, pulling a row-index level back out into columns. The MultiIndex-native alternative to melt/pivot_table for the same reshape, without needing to flatten column names into strings first.
transform()giữ nguyên 'transform()' — tính theo nhóm nhưng KHÔNG gộp hàng, trả về đúng số dòng gốcA groupby method computing an aggregation per group but returning it broadcast back to the original row count and row order, so every row in a group receives that group's value — unlike agg()/sum(), which collapses to one row per group. The pandas analog of a SQL window function like AVG(amount) OVER (PARTITION BY ...).
crosstab()giữ nguyên 'crosstab()' — đếm tần suất kết hợp giữa 2 cột phân loại, không cần values/aggfunc như pivot_tableA pandas function computing a frequency count cross-tab of two (or more) categorical columns by default — no values/aggfunc required for the plain-count case. Equivalent to pivot_table(index=a, columns=b, aggfunc="size", fill_value=0); adding values=/aggfunc= makes it functionally identical to pivot_table.
normalize=giữ nguyên 'normalize=' — đổi số đếm thành tỉ lệ %, chọn theo hàng/cột/toàn bảngA crosstab()/pivot_table() keyword turning raw counts into proportions: "index" normalizes each row to sum to 1, "columns" normalizes each column to sum to 1, "all" divides every cell by the grand total.
pd.qcut()giữ nguyên 'pd.qcut()' — chia theo thứ hạng/phân vị, mỗi bin có số lượng dòng gần bằng nhauA pandas function that sorts numeric values into a chosen number of bins (q=) by rank/percentile so each bin gets (as close as possible to) an equal COUNT of rows — the opposite trade-off from pd.cut(), which splits at fixed value edges regardless of resulting bin sizes. SQL cousin: NTILE(n) OVER (ORDER BY col).
rank(pct=True)giữ nguyên 'rank(pct=True)' — thứ hạng dạng phần trăm (0 đến 1)A Series method (building on Lesson 7's plain rank()) assigning each value its position as a fraction between 0 and 1 when the column is sorted — the percentile each row occupies. The mechanism qcut() is built on internally.
nunique()giữ nguyên 'nunique()' — đếm số giá trị PHÂN BIỆT (distinct) trong 1 cột, khác value_counts() (đếm theo từng giá trị) và count() (đếm số dòng không rỗng)A Series/DataFrame method returning the number of DISTINCT (unique) values in a column, ignoring how many times each one repeats and ignoring NaN by default — a different question from both value_counts() (count per value) and count() (count of non-null rows). SQL cousin: COUNT(DISTINCT col).
explode()giữ nguyên 'explode()' — tách 1 cột chứa list thành nhiều hàng, mỗi hàng 1 phần tử, các cột khác lặp lại theoA DataFrame method that takes a column containing list-like values and produces one row per element of each list, duplicating every other column's value alongside it — the opposite of collapsing rows, it multiplies them out. SQL cousin: UNNEST()/CROSS JOIN LATERAL unnest() (Postgres array unnesting), or exploding a JSON array column.
idxmax() / idxmin()giữ nguyên 'idxmax()/idxmin()' — trả về NHÃN INDEX của dòng có giá trị lớn/nhỏ nhất, khác max()/min() (trả về giá trị)Series methods returning the INDEX LABEL of the row holding the maximum/minimum value in that column, not the value itself — feed the result into .loc[] to get the full row back. Chained after groupby(), answers "which row is the top/bottom per group" in one line. SQL has no single equivalent: usually ORDER BY col DESC LIMIT 1 per group, or ROW_NUMBER() OVER (PARTITION BY ... ORDER BY col DESC) = 1.
pd.concat()giữ nguyên 'pd.concat()' — ghép nhiều DataFrame lại theo hàng hoặc cột, không so khớp giá trị như merge()A pandas function that stacks two or more DataFrames together — by row (axis=0, the default) or by column (axis=1) — with no matching or comparing of values at all, unlike merge(). ignore_index=True renumbers the result 0..N-1; keys= builds a MultiIndex tracking which input each row came from; mismatched columns are filled with NaN rather than raising. SQL cousin for axis=0: UNION ALL.
query()giữ nguyên 'query()' — lọc hàng bằng chuỗi biểu thức kiểu WHERE, thay cho boolean mask; dùng and/or/not và @ để lấy biến PythonA DataFrame method that filters rows using a string expression parsed like a SQL WHERE clause, instead of a boolean mask built from repeated df[...] comparisons. Uses Python's and/or/not keywords rather than &/|/~; an @ prefix pulls in a value from a Python variable in the surrounding scope instead of looking for a column of that name. Filters to identical rows as the equivalent boolean mask — the difference is purely readability, especially mid-method-chain where no DataFrame variable yet exists to mask against.
shift()giữ nguyên 'shift()' — dịch cả cột lên/xuống N dòng theo thứ tự hiện tại, tương đương LAG()/LEAD() trong SQLA Series method that shifts every value down (shift(1)) or up (shift(-1)) by a chosen number of rows, in the CURRENT row order — the direct analog of SQL's LAG()/LEAD() OVER (PARTITION BY ... ORDER BY ...). Rows that now have nothing to shift into return NaN. Trusts row order only, same as cumsum()/pct_change()/rolling() — sort first; skipping groupby() silently bleeds values across groups instead of raising. diff() is a named shortcut for "current value minus shift(1)."
np.where() / np.select()giữ nguyên 'np.where()/np.select()' — CASE WHEN vectorized, where() cho 2 nhánh, select() cho nhiều nhánhNumPy functions for vectorized if/else, with no per-row Python function call. np.where(cond, a, b) is CASE WHEN cond THEN a ELSE b END for a single two-way split. np.select(conditions, choices, default=...) takes parallel lists and picks the choice tied to the FIRST matching condition in order (falling through to default) — CASE WHEN ... WHEN ... ELSE END for 3+ branches. Comparisons against NaN are always False, so a missing input silently lands in the else/default branch rather than raising.
listgiữ nguyên 'list' — cấu trúc dữ liệu dạng danh sách có thứ tựPython's built-in ordered-sequence type, written with square brackets ([a, b, c]) — a general Python idiom, not pandas-specific. np.select() takes two parallel lists: one of boolean conditions, one of matching choice values.
select_dtypes()giữ nguyên 'select_dtypes()' — lọc cột theo KIỂU dữ liệu, không phải theo tênA DataFrame method returning a new DataFrame containing only the columns whose dtype matches include= (or excluding those matching exclude=) — selects columns by TYPE instead of hardcoding names. include="number"/exclude="number" is the common case: grab every numeric column (or every non-numeric one) at once, whatever the table's actual column names turn out to be.
category dtypegiữ nguyên 'category dtype' — mã hoá cột thành bảng tra cứu nhỏ (categories) + số nguyên cho mỗi hàng, giống ENUM/foreign key trong SQLA pandas dtype that stores a column as a small lookup table of distinct values (.cat.categories) plus one small integer code per row pointing into it, instead of repeating the full string in every row — the SQL ENUM/normalized-foreign-key model, inside one column. Best for low-cardinality columns (few distinct values) repeated across many rows: memory_usage(deep=True) drops noticeably and comparisons/groupby run on small codes instead of full strings. Converting to an explicitly fixed CategoricalDtype that's missing a real value silently turns that value into NaN — no error raised.
view vs copygiữ nguyên 'view' / 'copy' — view dùng chung vùng nhớ với bản gốc, copy thì tách biệt hoàn toàn, khó biết chắc slice nào là gìFiltering or slicing a DataFrame can return a view (shares underlying memory with the original — mutating it can affect the original too) or a copy (fully independent memory) depending on internal details you often can't predict just by reading the code. Contrast with SQL, where a materialized query result is always a fresh, independent copy — this ambiguity has no real SQL equivalent.
chained indexinggiữ nguyên 'chained indexing' — viết 2 lượt [] liên tiếp trong 1 dòng (hoặc 2 dòng), ví dụ df[mask]["col"] = value, thay vì gộp lại thành 1 lượt .loc[]Writing an assignment as two indexing operations back-to-back — df[mask]["col"] = value — instead of one combined .loc[row_selector, col_selector] = value call. pandas evaluates the first bracket as a separate intermediate object (view or copy, ambiguous) before the second bracket's assignment ever runs, so the write may or may not reach the original DataFrame. The classic "no crash, quietly wrong" pandas trap.
SettingWithCopyWarninggiữ nguyên 'SettingWithCopyWarning' — cảnh báo cũ của pandas khi nó không chắc bạn đang ghi vào view hay copyA runtime warning older pandas (< 3.0) prints when it detects an assignment into something that might be a view of another DataFrame — pandas flagging its own genuine uncertainty rather than guessing silently. On current pandas with Copy-on-Write, a single-line chained assignment instead raises ChainedAssignmentError outright, while the same trap split across two statements (sub = df[mask]; sub["col"] = value) now raises nothing at all and silently fails to update the original.
.copy()giữ nguyên '.copy()' — tạo bản sao độc lập thật sự trước khi sửa, để không còn mơ hồ view/copyA DataFrame/Series method returning a genuinely independent copy with its own memory. The explicit fix for the view-vs-copy ambiguity: filter/slice, call .copy(), assign to its own variable, then mutate that — guaranteed never to touch the original. When the intent is instead to mutate the original DataFrame directly, the correct tool is one combined .loc[row_selector, col_selector] = value call, not .copy().
Copy-on-Write (CoW)giữ nguyên 'Copy-on-Write' (CoW) — chế độ mặc định từ pandas 3.0, coi mọi thao tác như luôn tạo bản sao, ghi vào bảng con không làm lộn xộn bảng gốcA pandas execution mode, the permanent default starting in pandas 3.0, where every DataFrame/Series behaves as if copied on every operation — removing the view-vs-copy ambiguity by always erring toward independence. Side effect: single-line chained assignment now raises ChainedAssignmentError instead of only warning, while the two-statement version of the same trap raises nothing and silently no-ops.
